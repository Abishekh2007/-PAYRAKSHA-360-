====================================================
14. EXPLAINABLE AI
====================================================

Create a “WHY THIS WARNING?” button.

When clicked, show a side panel.

Example:

RISK: 92/100

Risk decomposition:

Recipient novelty       +25
Urgency                  +20
Impersonation            +18
Amount anomaly           +12
Context mismatch         +17

Then:

PLAIN-LANGUAGE EXPLANATION

“The request is unusual because it uses urgency, involves an unfamiliar payment destination, and differs from the user's simulated payment pattern.”

Add:

“PAYRAKSHA does not treat any single signal as proof of fraud. Multiple contextual signals are evaluated together.”
