====================================================
1. PRODUCT VISION
====================================================

Build a visually impressive, technically credible, fully interactive web application that demonstrates how PAYRAKSHA can identify suspicious digital-payment situations BEFORE money is sent.

The application must NOT be just a fraud dashboard.

Its central innovation is:

“PAYRAKSHA evaluates the entire payment situation — message + URL + QR + recipient + amount + user context + behavioural signals + social-engineering signals — and explains WHY the payment may be dangerous before the user pays.”

The system should detect combinations of suspicious signals rather than simply classifying something as spam.

Core workflow:

MESSAGE / URL / QR / PAYMENT CONTEXT
        ↓
SIGNAL EXTRACTION
        ↓
CONTEXTUAL RISK ENGINE
        ↓
SCAM PATTERN DETECTION
        ↓
EXPLAINABLE RISK SCORE
        ↓
SCAM DNA
        ↓
ATTACK CHAIN
        ↓
SAFE ACTION RECOMMENDATION
